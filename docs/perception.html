Being noticed

What alarms birds, how hard, and how to alarm them on purpose. Every APawn already does, with no per-character setup.

Four ways in

Deduped as component > interface > class list, so the more specific one always wins.

Way
Flock Disturbance Componenton the actor. Threat Weight (1), Max Radius (1200), Enabled, and SetDisturbanceEnabled for a source that comes and goes. Always outranks the class list
IFlockDisturbanceInterfacefor a type your own module owns. GetFlockThreatWeight and GetFlockThreatRadius are read once at registration; only IsFlockThreatActive is polled
Auto Register Disturbance ClassesProject Settings → Game → Flock. Defaults to APawn, at Auto Source Threat Weight 1 and Auto Source Radius 1200
FlockIgnore actor tagopts an actor out entirely
Position Component on the disturbance component picks which component's position the birds actually track. Needed whenever physics simulates on a child rather than the root: the mesh rolls away while the actor's transform stays where it spawned, so the birds would watch an empty spot.

IsFlockThreatActive is polled every frame, and only for actors that implement the interface. It is the hook for unnoticed while crouched or hidden.

How alarm builds

Alarm accumulates per bird from its flock's four strongest threats, and decays when they leave. Per-bird cost is bounded by those four slots, not by how many sources exist in the world, and a flock with none is skipped whole.

PropertyDefault
Proximity Exponent3how sharply alarm falls off with distance, and the knob for where birds break. At 1 something at the edge of its radius is already mildly alarming; at 3 the halfway point contributes an eighth as much. No radius change substitutes for it
Safe Radius150inside which proximity is already full
Max Notice Radius1200this species' attention span, capping whatever radius a source claims
Panic Radius120close enough to flee outright regardless of the accumulator. Catches a sprint or a teleport
Base Weight0.35how much merely being nearby counts
Closing Weight0.8how much approaching counts
Speed Weight0.3how much moving fast counts, whatever the direction
Closing Speed Ref400closing speed treated as maximally alarming
Speed Ref600absolute speed treated as maximally alarming
Max Threat Rate2ceiling on the summed contribution, so a crowd is not instantly terrifying
Alert Gain1.5how fast alarm builds
Alert Decay0.6how fast it bleeds away once nothing is alarming
Closing Weight is more than twice Base Weight by default, which is what makes birds react to being walked at rather than to being near. A player who strafes past a flock at the same distance barely moves it. Lower Closing Weight and raise Base Weight for birds that just do not want anyone nearby.

Perk and flee

PropertyDefault
Perk Threshold0.25alarm before a bird looks up
Perk Release Ratio0.6fraction of that it must fall back to before relaxing. Below 1, so birds do not flicker
Flee Threshold0.75alarm before it launches
Threshold Jitter0.25spread across birds, so a flock reacts raggedly rather than as one animal
Turn Rate Degrees180/show fast an alert bird turns to face what alarmed it
Turn Deadband Degrees12yaw error below which the turn clips give way to idle, so they do not chatter

Contagion

PropertyDefault
Contagion Strength1.2how hard one bird taking off alarms its flockmates
Contagion Window0.4show long that lasts
Two floats in the flock's shared fragment, not a neighbour query. It does not fall off with distance, it does not cross between flocks, and every bird in the volume feels the same amount. That is why the window is short.

After landing

PropertyDefault
Landed Cooldown3show long the refractory period lasts
Refractory Decay Scale3alert decays this much faster during it
Refractory Flee Bonus0.15the flee bar is raised by this much during it

Together these are what stop a flock bouncing: land, launch, land, with the thing that spooked it still standing there.

Scaring them

A scare is a source with a lifetime, not a command. For Duration it sits in the same list a walking player does and is felt through the same falloff, so birds in the middle break and scatter while the ones at the edge only look round, and none of them do it on the exact frame of the bang.

From an animation

Add a Scare Flock notify to any montage - a swing, a landing, a shout - plus Socket Name to centre it on a socket rather than the actor.

This is the preferred way in: where in a swing the noise happens is a property of the animation, and only whoever authored it knows where that falls. It no-ops in preview and editor worlds.

From code

#include "System/FlockStatics.h"

UFlockStatics::ScareFlock(this, GetActorLocation(), /*Radius*/ 2000.f);

Nothing to register, nothing to clean up. ScareFlockAtActor is the same centred on an actor, read once at the call and not tracked. Both are BlueprintCallable.

PropertyDefault
Radius1500how far it carries. Not capped by Max Notice Radius. The notify defaults to 2000
Weight8how alarming. Comparable to a source's threat weight, where a walking character is 1, so the default is emphatic
Duration0.6show long it keeps alarming. Alarm accumulates over this - shorten it for a flinch, lengthen it for a rout
Falloff1linear, deliberately rather than the species' curve, because a scare should carry to its edge. Raise it to pull the reaction in tight

Seeing it

flock.Debug.Perception 1    bird state, alert level, and the clip and frame it is playing
flock.Debug.Perception 2    also threat sources
flock.Debug.Perception 3    also flock bounds, the attractor and blocking volumes in use

Perception 2 is how you tell a source that is not registered from one that is registered and not reaching. If it draws, the birds can see it, and whatever is wrong is in the falloff.
