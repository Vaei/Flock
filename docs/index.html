Flock

Bird flocks that idle, notice you, and scatter. Mass simulation, one instanced mesh draw, animation baked into textures. No actor per bird, no skeletal meshes, no anim blueprints, no runtime traces.

cd YourProject/Plugins
git clone git@github.com:Vaei/Flock.git

Install it →

Not officially released. Expect bugs and updates without versioning. Documentation is still filling in.

Why

Birds are the cheapest thing in a level to want and the most expensive to build. A dozen actors, each with a skeletal mesh, an anim blueprint and a behaviour tree, is a real budget spent on set dressing nobody will walk up to.

Flock spends none of it. A bird is a handful of floats in a Mass chunk; a whole flock is one instanced mesh component and two calls a frame; the animation is a texture the vertex shader reads. Nothing traces, nothing collides, nothing replicates, and none of it exists on a dedicated server.

What you get

They notice youAnything can alarm them, scored on how near it is, how fast it is closing and how much it counts for. Perk up, turn to track, then go. Per-bird thresholds, so no two leave at once.
Alarm is contagiousOne bird leaving alarms the rest, so a flock cascades instead of switching.
A scatter splitsSome relocate far from what frightened them, some wheel overhead and come back once it is calm. The ratio is authored per flock.
A settled flock is never stillRest breaks, a few dawdled steps, glances, and moves between perches with nothing wrong.
Reserved perch slotsNo two birds ever claim one branch. Slots from mesh sockets, a spline, a grid or placed by hand, on any actor, landing on the authored rotation.
Clip changes that do not snapThe bake works out which frame of each clip best continues the one being left, so a bird entering a glide has its wings already up.
Per-flock audio and VFXOne MetaSound bed fed live distance, count, alert and airborne ratio, with triggers for cascades, plus a pool of spatialised one-shots.
Four LOD tiersStructural, not branched: the tier is a tag, so a distant flock's chunks are never visited at all.

Twenty minutes to a flock

  1. Clone, build, enable.
  2. Bake your bird: three material settings, an empty species asset, one window.
  3. Map the clips. Idle is the only one required.
  4. Drag a Flock Volume out of the Flock menu. Set Species and Spawn Count.
  5. Play, and walk at them.

Birds are cosmetic. They do not collide, they are not replicated, two clients will not see the same bird in the same place, and nothing about them runs on a dedicated server. If gameplay has to agree about a bird, this is the wrong tool.
