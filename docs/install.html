Install

UE5.8+. A C++ project, because the plugin has source. Twenty minutes to birds on the ground.

Get it

cd YourProject/Plugins
git clone git@github.com:Vaei/Flock.git

As a submodule, if your project is a git repo:

git submodule add git@github.com:Vaei/Flock.git Plugins/Flock
git submodule update --init --recursive

Or download the ZIP from the repo and unpack it into Plugins/. Then regenerate project files, build, and enable Flock in the plugin browser.

It pulls in Anim to Texture and Niagara, both engine plugins, and enables them for you. Nothing else is required.

Check it worked

A Flock dropdown appears in the level editor toolbar, and a Flock category appears in Place Actors. If neither is there, the module did not load - check the log for LogFlock.

Your first flock

You need a baked bird before a volume does anything, so bake one first. Then:

  1. Drag a Flock Volume out of the Place section, or click the entry to drop one in front of the camera.
  2. Scale the box over the ground the birds should own.
  3. Set Species, and Spawn Count to something small - 8 is plenty to judge by.
  4. Press Play. Walk at them.
Nothing else is needed for a working flock. Perches, blocking volumes and audio are all optional and all additive - a volume on its own gives you birds that stand about, dawdle, glance, take off when you approach and come back down.

Debug draws

All non-shipping, all ECVF_Cheat.

flock.Debug.Perception 1    bird state, alert level, and the clip and frame it is playing
flock.Debug.Perception 2    also threat sources
flock.Debug.Perception 3    also flock bounds, the attractor and any blocking volumes in use
flock.Debug.Slots 1         perch slots: green free, yellow reserved, red occupied
flock.Debug.Slots 2         also which bird holds each one

Perception 1 is the one to reach for first: it names the clip on each bird, so a wrong animation index shows up without opening a data asset.
