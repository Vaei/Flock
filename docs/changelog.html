Changelog

1.0.0

Simulation

  • Mass (ECS) flocks: no actor per bird, one instanced mesh draw per flock, animation baked into textures
  • Perception scored on proximity, closing speed and raw speed, with per-bird perk and flee thresholds and jitter
  • Contagion, so one bird leaving alarms the rest and a flock cascades instead of switching
  • Scatters that split: some relocate away from what frightened them, some wheel overhead and come back
  • Idle behaviour: weighted rest breaks, dawdling on open ground, glances using the turn clips
  • Voluntary moves between perches, with a standing target for how much of the flock is airborne
  • Reserved perch slots, resolved in one game-thread pass so two birds never claim one
  • Slots from a box grid, mesh sockets, a spline or typed in by hand, on any actor
  • Continuous proportional banking from the turn itself, with optional bank and glide clips
  • Blocking volumes, box and sphere, with a steering margin and a hard placement backstop
  • Four LOD tiers as tags, so a culled flock's chunks are never visited
  • Separation between airborne flockmates, chunk-local, tier-limited
  • Nothing replicated, and three separate gates keeping it off a dedicated server

Animation

  • Pose-matched clip changes, baked, so a looping clip opens on a pose near the one it replaced
  • MF_FlockBoneAnimation, a drop-in for the engine's bone animation function with optional frame interpolation behind a static switch
  • Frame interpolation as a species setting with its own LOD tier limit
  • Mirrored rest breaks as one entry, so a pair spends one weight between them
  • Per-clip play rate, so one clip authored at the wrong speed does not need a re-bake

Audio and VFX

  • One MetaSound bed per flock, fed distance, bird count, mean alert and airborne ratio, with takeoff and land triggers
  • Spatialised one-shots from a pool, per clip and per rest break, picked at random from a list
  • Sound delay, so a caw lands where the beak opens
  • Batched Niagara bursts, one component per flock
  • OnClipStarted, on the game thread, for everything else

Tooling

  • One bake window that creates the mesh, all three textures and the data asset, validates every texture before starting and re-points every material instance afterwards
  • The bake recipe stored on the species, so moving between birds costs nothing
  • The lightmap moved off the UV channel the bake needs, which is the most common first-run failure
  • Pose match table built at the end of a bake, and rebuildable on its own
  • Perch baking for every placed component in a level
  • A VAT preview actor that scrubs in the viewport without PIE
  • Python entry points for batching or CI
  • Flock toolbar menu with draggable placement entries, and a per-developer hide
  • stat flock and the Insights group from one macro
  • Debug draws for perception and slots, and overrides for separation, pose matching and interpolation
